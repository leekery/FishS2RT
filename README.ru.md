# FishS2RT

[English](README.md) | **Русский**

FishS2RT — Python SDK для ускоренного native-инференса и потоковой генерации
Fish Audio S2 Pro в реальном времени. Он объединяет постоянный оптимизированный
CUDA runtime, живую выдачу PCM, точный финальный рендер и кеширование
референсного голоса за компактным API. При сборке из исходников выбирается
целевая CUDA-архитектура, а готовые бинарные релизы указывают поддерживаемые
архитектуры.

Имя Python-пакета и публичный импорт намеренно остаются `fish_s2`:

```python
from fish_s2 import FishS2
```

SDK можно подключить к выбранным пользователем проигрывателю, интерфейсу,
сервису и системе управления моделями. Веса и голосовые референсы предоставляет
само приложение.

## Основные возможности

- постоянный native-процесс, загруженная модель и кеш подготовленных референсов;
- точная финальная генерация и живой поток PCM16 через единый API;
- оптимизированные Q8_0- и BF16-пути без изменения весов модели;
- инкрементальный ModifiedDAC с кольцевым KV-кешем и ограниченным состоянием CNN;
- независимый финальный рендер точной длины после живого воспроизведения;
- опциональные lossless-профили хранения BF16 P2/P3;
- Python API без обязательных зависимостей и доступ к расширенным native-настройкам;
- выбор CUDA-архитектуры при сборке вместо привязки к конкретной видеокарте.

## Установка из исходников

```powershell
git clone https://github.com/leekery/FishS2RT.git
cd FishS2RT
python -m pip install -e .
fish-s2-build
```

`fish-s2-build` собирает native runtime, если его ещё нет в исходном checkout.
По умолчанию архитектура выбирается автоматически. Для первой тестовой
платформы её можно задать явно:

```powershell
fish-s2-build --cuda-arch 120a-real
```

Готовые бинарные релизы должны перечислять скомпилированные CUDA-архитектуры в
`BUILD_INFO.txt`. Установка библиотеки не скачивает веса: путь к
совместимому локальному Q8_0- или BF16-GGUF задаёт пользователь.

Пользователь готового релиза может установить SDK вместе с точно совместимым
Windows runtime. Оба дистрибутива собираются из одного Git-тега, а публичный
импорт остаётся `fish_s2`:

```powershell
python -m pip install "fish_s2[runtime]"
```

## Первое клонирование голоса

```python
from fish_s2 import FishS2

with FishS2(r"C:\models\fish-audio-s2-pro-q8_0.gguf") as tts:
    voice = tts.prepare_voice(
        r"C:\voices\reference.wav",
        "Точная расшифровка всего, что произнесено в референсе.",
    )
    audio = tts.generate("Первая озвучка готова.", voice=voice)
    audio.save("result.wav")
```

Модель остаётся в памяти между вызовами. Повторно используйте один экземпляр
`FishS2` и объект `Voice`; вызов `unload()` освобождает видеопамять.

## Поток звука во время генерации

```python
from fish_s2 import FishS2, Sampling

with FishS2(r"C:\models\fish-audio-s2-pro-q8_0.gguf") as tts:
    voice = tts.prepare_voice("reference.wav", "Точная расшифровка референса.")
    sampling = Sampling(stream_chunk_frames=4)

    with tts.stream(
        "Звук можно воспроизводить до завершения всей реплики.",
        voice=voice,
        sampling=sampling,
    ) as stream:
        for chunk in stream:
            audio_sink.write(chunk.pcm)  # PCM16 little-endian

        final = stream.result()
        final.save("exact-final.wav")
```

SDK не навязывает библиотеку вывода звука. `chunk.pcm` можно отправлять в
`sounddevice`, сокет, браузерный мост или другой приёмник. Live-чанки
оптимизированы для немедленного воспроизведения и не обязаны побайтно совпадать
с независимым точным рендером. Для канонического файла сохраняйте
`stream.result()`.

## Точность весов и профили runtime

| Профиль | Смысл | Рекомендуемое применение |
|---|---|---|
| Q8_0 | Квантованные веса модели | Меньший расход VRAM и практичный профиль для 12 ГБ |
| BF16/raw | Исходные BF16-значения в GGUF-пути | Максимальная доступная точность весов |
| BF16/P2 | Точное двухплоскостное хранение отдельных Fast-AR-весов | Расширенный opt-in |
| BF16/P3 | Точное трёхплоскостное/HMC-хранение с fallback на P2 | Расширенный opt-in |

P2 и P3 — lossless-представления хранения, а не дополнительная квантизация
весов. Точность модели, sampling и сегментация текста остаются явным выбором
приложения.

## Измеренная производительность

Результаты относятся только к сохранённым тестовым нагрузкам и первой
проверенной системе; это не универсальная гарантия производительности.

| Нагрузка на RTX 5070 12 ГБ | Результат относительно закреплённого baseline |
|---|---:|
| Q8, обычный текст, matched final | средняя задержка ниже на 24,12% |
| Q8, клонирование голоса, matched final | средняя задержка ниже на 21,46% |
| BF16, фиксированная нагрузка, matched final | средняя задержка ниже на 16,52% |
| Q8, live-стриминг | скорость 1,745x realtime |
| BF16/P3, live-стриминг | скорость 1,304x realtime |

Итоговые WAV совпали по SHA-256 внутри каждого контролируемого сравнения.
Сходство live-потока с финальным рендером составило около 46,6 дБ SNR для Q8 и
47,1 дБ для BF16/P3. Эти цифры относятся к сохранённым нагрузкам на одной
тестовой системе и не являются универсальной гарантией производительности.
